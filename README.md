### 🎯 Learning Purpose

📌 This project demonstrates how to connect a **Spring MVC JSP frontend**
with a **MySQL database using Spring Data JPA and Hibernate**.

💡 The main focus is on understanding:

🔹 Form data handling  
🔹 Spring MVC Controller  
🔹 Entity mapping  
🔹 JPA Repository  
🔹 Saving data into MySQL  
🔹 Reading data from MySQL  
🔹 Displaying database data on JSP
